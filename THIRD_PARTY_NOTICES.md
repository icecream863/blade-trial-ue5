# Third-party resources

## Unreal Engine template content

The character meshes, materials, textures, rigs and base animations under
`Content/Characters/Mannequins` originate from Epic Games' Unreal Engine 5.8
Third Person template resources. Input and animation assets include project
adaptations of those templates. Combat montages reference the template animation
sequences.

These resources remain subject to the [Unreal Engine EULA](https://www.unrealengine.com/eula/unreal),
including its terms for Examples. They are not presented as original character
art or original animation work.

## GhostSamurai animation and effects

The local demo uses GhostSamurai character animation, weapon and VFX assets under
`Content/GhostSamurai_Bundle`. This private repository excludes that bundle and
newly copied animation and Niagara assets. A user who wants to recreate
the complete playable project must obtain the asset pack under their own license
and install it at the same Unreal content path before running the asset setup
scripts. The repository's C++ and documentation do not convey a license
to those external assets.
